# Hub de Documentação Técnica: Sistema de Rifas

Bem-vindo ao hub central de documentação técnica do sistema de rifas. Esta documentação é voltada para a equipe de engenharia (desenvolvedores e agentes autônomos) e é mantida junto com o código fonte (*Docs as Code*).

## Navegação

A documentação está dividida por tópicos, facilitando a manutenção, o onboarding de novos desenvolvedores e o entendimento das regras de negócio.

- [00. Convenções e Padrões de Código](./00-convencoes.md) - Diretrizes gerais de engenharia e leis de arquitetura.
- [01. Modelagem de Dados](./01-dados/README.md) - Estrutura do Firestore, dicionário de dados, invariantes e ciclos de vida.
- [02. Arquitetura (C4 Model & UML)](./02-arquitetura/README.md) - Diagramas de contexto, containers, mapeamento do Front/Backend, Casos de Uso e Fluxos de Sequência.
- [03. Contratos de API](./03-api/README.md) - Mapeamento das rotas Express, payloads camelCase, DTOs e segurança.
