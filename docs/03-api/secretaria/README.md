# API: Secretaria

Este módulo contém as rotas do backoffice do sistema. Nele, a diretoria ("presidência", "rh", "secretaria") possui os privilégios para orquestrar e auditar quem tem acesso ao sistema (aderidos) e guardar documentos estáticos organizacionais.

## Catálogo de Endpoints

- [Gestão de Aderidos (RH)](./aderidos.md) - Cadastros prévios de permissões, perfis e Faixas de Rifa.
- [Documentos Organizacionais](./documentos.md) - Envio Multipart de imagens, atas e contratos para o Storage.
